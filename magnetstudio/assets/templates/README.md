# תבניות מצורפות (Bundled templates)

התיקייה הזו היא **לקריאה בלבד** – דוגמאות שמגיעות עם האפליקציה (`sample_*`).
תבניות של המשתמש נשמרות בתיקיית הנתונים שלו (`paths.user_templates_dir()`):

| מערכת | תיקייה |
|-------|--------|
| Windows | `%LOCALAPPDATA%\MagnetStudio\data\templates` |
| macOS | `~/Library/Application Support/MagnetStudio/data/templates` |

רשימת המסגרות בחלון הראשי מאחדת את שתיהן (תבנית משתמש באותו שם גוברת על דוגמה).
עריכה של דוגמה ושמירה → נשמרת כעותק בתיקיית המשתמש.

## פורמטים
- **JSON** – תבנית חיה (חלונות תמונה, טקסט עברי, גרפיקה, קרדיט). זוג אנכי+אופקי בקובץ אחד.
  גרפיקה של תבנית ב-`<שם>_assets/` לצד הקובץ.
- **PNG** – מסגרת מוכנה עם שקיפות, בגודל היעד המדויק ב-300 DPI:
  7.5x10 → 886×1181 · 10x10 → 1181×1181 · 15x20 → 1772×2362 · 5x15 → 591×1772

שם קובץ מומלץ: `<שם>_<גודל>.json` / `.png` (למשל `wedding_7.5x10.png`).
