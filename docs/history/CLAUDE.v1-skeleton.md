# MagnetStudio

## מה זה
אפליקציית דסקטופ (Windows & macOS) להכנת תמונות מגנטים: הלבשת מסגרות על תמונות והדפסתן.

## דרישות עיקריות
- **פלטפורמות:** Windows ו-macOS (Python + PyQt6).
- **גדלי מגנטים (ס"מ) ב-300 DPI:**
  | גודל | פיקסלים |
  |------|---------|
  | 7.5x10 | 886 x 1181 |
  | 10x10 | 1181 x 1181 |
  | 15x20 | 1772 x 2362 |
- **מצבי הדפסה:**
  1. **מדפסת טרמית** – תמונה אחת לכל הדפסה, בגודל המגנט המדויק.
  2. **פריסת A4** – סידור כמה מגנטים על דף A4 (2480x3508 ב-300 DPI) עם שוליים וקווי חיתוך.
- **תיקייה במעקב (watchdog):** תמונות חדשות שנכנסות לתיקייה מעובדות אוטומטית (למשל באירועים).

## מבנה הפרויקט
```
main.py              נקודת כניסה
core/                מנוע העיבוד
  sizes.py           הגדרות גדלים והמרות ס"מ↔פיקסלים
  image_processor.py חיתוך/התאמה של תמונה לגודל היעד
  framer.py          הלבשת מסגרת (PNG שקוף) על תמונה
  layout.py          פריסת מגנטים על A4
  printer.py         שליחה למדפסת (טרמית / A4)
  watcher.py         מעקב אחרי תיקיית קלט
  settings.py        טעינה ושמירה של הגדרות
ui/                  ממשק משתמש (PyQt6)
  main_window.py     חלון ראשי
  frame_editor.py    עורך מסגרות
config/settings.json הגדרות ברירת מחדל
assets/templates/    מסגרות (PNG עם שקיפות) ודוגמאות
```

## מוסכמות
- כל חישובי הגודל עוברים דרך `core/sizes.py` – לא לכתוב מספרי פיקסלים בקוד.
- כל העיבוד ב-300 DPI; שמירת קבצים עם `dpi=(300, 300)`.
- `core/` לא מייבא מ-`ui/` (הפרדה בין לוגיקה לממשק).
- מסגרות הן PNG בגודל היעד המדויק, עם אזור שקוף במקום התמונה.

## הרצה
```
pip install -r requirements.txt
python main.py
```
